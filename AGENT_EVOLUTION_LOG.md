# Agent Evolution Log

This file tracks the historical evolution of the AI Agent's rules, constraints, and learnings over time. New rules are synthesized and added to `AGENTS.md`, while the chronological record of these changes is maintained here to prevent context bloat.

* **[2026-07-27]** Initialized unified `AGENTS.md` architecture and introduced the Continuous Agent Evolution mechanism with a separate log file to track new skills and rules over time without degrading performance.
* **[2026-07-27]** Resolved UI overlap issue with `.quiz-actions-dropdown` z-index stacking and enforced inline-flex displays instead of inline-block to fix icon alignments across EJS templates (Quiz, Index, Edit).
* **[2026-07-27]** Fixed AI State Leakage in the `resolve_question` endpoint. The AI was regurgitating wrong answers because the existing answer fields were being passed in the JSON context. Now clearing `answer` and `options` before sending data to Gemini.
* **[2026-07-27]** Fixed Vision Context loss in `resolve_question`, `solve_worksheet`, `polish_questions`, and `generate_quiz_from_extracted`. The base64 image strings embedded within question HTML were not being processed by Gemini Vision properly since they were passed as raw text strings. Modified the endpoints to extract the base64 data and pass it properly using the `@google/genai` `inlineData` structure, replacing the HTML strings with `[IMAGE_PROVIDED_IN_VISION_CONTEXT]` placeholders to avoid context bloat, and then safely restoring the image HTML afterward.
* **[2026-07-27]** Fixed an issue where the AI was generating literal '\n' strings instead of real newlines in JSON outputs due to prompt phrasing. Also explicitly instructed the AI not to wrap plain text words in Math LaTeX '$' tags.
* **[2026-07-27]** Patched safeParseJSON's fixJsonLatexEscapes to correctly escape literal newline, return, and tab characters inside JSON strings, preventing extraction failure when the AI generates literal newlines for multi-part questions. Also applied the extractionSchema to the recovery route and improved missing index logic to respect the minimum detected index.
* **[2026-07-28]** Successfully modularized monolithic `server.ts` (~2,770 lines) into clean, maintainable files under `src/`: `src/types.ts` for interfaces, `src/store/db.ts` for data persistence/Firestore sync, `src/middleware/auth.ts` for authentication, `src/services/` for business logic (`gemini.ts`, `pdf.ts`, `socket.ts`), and `src/routes/` for Express routers (`authRoutes`, `quizRoutes`, `liveRoutes`, `gradingRoutes`, `aiRoutes`, `resultsRoutes`, `adminRoutes`, `worksheetRoutes`). Streamlined `server.ts` to a clean ~60 line entry point.
